# Person types and work types

## Person type (Employee / Contractor / Placeholder)

This is set on each person’s profile:

- **Employee** — regular staff member
- **Contractor** — external or contingent worker
- **Placeholder** — planning slot without a real person yet

On the schedule, filter by **Person type** to show only contractors (or employees, etc.).

## Work type (Full-time / Part-time)

On the **People** page, **Work type** describes employment hours pattern (Full-time vs Part-time). This is separate from Person type and is used when filtering the People directory.

## Contractors on the schedule

To see contractor allocations: go to the schedule, open Filters, and set **Person type** to **Contractor**. Confirm the date range includes the work you expect.
