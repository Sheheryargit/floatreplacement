# Person tags and project tags

Tags are labels you attach to people or projects so you can find and group them quickly.

## Person tags

Person tags live on each person’s profile (for example “bench”, “urgent”, or “contractor-pool”). They appear in the People directory and on the schedule.

On the **Schedule**, open **Filters** and choose **Person tag** to show only people with specific tags. Multiple filter rules combine with AND logic — every rule must match.

## Project tags

Project tags label engagements in the Projects registry. They help when searching projects and when filtering allocations by project tag on the schedule.

## Starred tag presets

You can star a person tag in the filter menu and save it as a **starred filter** for one-click reuse later.
